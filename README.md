# 📊 Power BI Desafio #01 - Análise de Vendas e Lucro

> Dashboard desenvolvido no Desafio #1 do curso **Power BI Analyst** da Juliana Zanelatto

## 📋 Sobre o Projeto

Este projeto faz parte do primeiro desafio prático do curso de Power BI Analyst. O objetivo foi replicar 2 páginas do curso e criar uma terceira página do zero, aplicando conceitos de criação de visuais, tooltips e organização de layout.

**Dataset utilizado:** Financial Sample.xlsx

## 🎯 Objetivos do Desafio

1. Replicar duas páginas já criadas durante o curso
2. Criar uma terceira página com os seguintes visuais:
   - **Mapa 1:** Soma de Sales e Unidades Vendidas por País
   - **Mapa 2:** Soma de Lucro (Profit) por País
   - **Gráfico de Pizza:** Lucro por Segmento
3. Verificar disposição dos visuais no relatório
4. Modificar nomes dos visuais para algo mais claro e direto
5. Configurar dicas de ferramentas com campos relevantes
6. Publicar o relatório

## 📸 Visão Geral do Dashboard

### Página 3 - Análise Geográfica e Segmentação

| Visual | Descrição | Insight Principal |
| --- | --- | --- |
| **Mapa de Vendas** | Soma de Vendas ($) e Unidades Vendidas por País | Identifica mercados com maior volume |
| **Mapa de Lucro** | Soma de Lucro (Profit) por País | Mostra países mais rentáveis |
| **Gráfico de Pizza** | Distribuição de Lucro por Segmento | Revela segmentos com maior margem |
